You are performing a **comprehensive, hands-on review** of Squadron Ops — a
naval aviation operations web demo (HSC / MH-60S). Your job is to determine
whether this build is **credible and demo-ready** for a mixed audience of SDOs,
maintainers, senior aviators, and program managers.

Be thorough, skeptical, and specific. Execute real clicks and form submissions —
do not infer behavior from static HTML alone.

  reported as Critical.

## Section 3 — WTM Readiness (`/readiness`)

This is the **"better than SHARP"** moment. Be rigorous.

Check:
- All 8 capability areas render: MOB, FSO, ASU, SOF, PR, STW, LOG, MIW
- Squadron overall T-rating and per-area T-1/T-2/T-3 counts
- Click an area → drill-down with per-pilot:
  - Contributing factors (plain language, not empty for T-2/T-3 pilots)
  - Anchor task status: current / stale / absent with days-since
  - T-1/T-2 window days shown
- Aircrew section present below pilot matrix
- **Export PDF** button: downloads PDF or shows clear 503/error (not silent fail)
- Page copy distinguishes WTM T-ratings from Table B-2 currency (Dashboard)

Domain flag: implausible all-T-3 squadron, missing areas, or factors that
contradict visible task/currency data.

## Section 4 — Maintenance (`/maintenance`, `/maintenance/{id}`)

Check squadron rollup (`/maintenance`):
- Computed FMC/PMC/NMC stat strip (not stamped-only)
- Phase forecast and release forecast cards
- Aircraft cards show stamped vs computed when they differ
- Yellow drift banner when applicable

Check aircraft detail (find side numbers on cards — **ids change each reseed**):
| Side | Expected after reseed |
|------|----------------------|
| 614 | Stamped FMC, computed PMC — QA release should **succeed** |
| 615 | DOWNING in work — QA release **blocked** with clear reason |
| 617 | AWP / NMCS drift — QA release **blocked** |

On detail page verify:
- Inspections list with overdue/downing indicators
- Open discrepancies show MAF numbers, JCN, work status, type WO
- Work order chain visible (not orphaned discrepancies)
- Aircraft logbook entries
- Per-tail release forecast
- **New discrepancy** modal submits without error
- **Update discrepancy** modal works
- **QA Release** modal: success toast on 614; blocker message on 615/617
- Terminology: "QA release / safe for flight" — **never "RTS"**

## Section 5 — Sortie cascade (core demo spine)

**Routes:** `/sorties`, `/sorties/{id}`, `/sorties/{id}/complete`, `/crew/{id}`

Execute end-to-end:
1. Find an **incomplete** sortie (best: day+2 evening ASU P211 for NVG/night)
2. Open Complete Sortie
3. Verify validation warnings for missing times/hours
4. Fill takeoff/landing, per-crew hours; use "Apply mission profile" if present
5. Submit successfully (no console errors, no failed POST)

Then on assigned HAC crew page (`/crew/{id}`):
- Applicable currency renewed (e.g. NIGHT_NVD date advanced)
- WTM readiness card shows area ratings
- Degraded areas show anchor task breakdown

Optional: complete SIM_TOFT P200 (day+3) — sim-ineligible currencies should not
advance incorrectly.
